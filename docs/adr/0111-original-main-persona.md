# 0111. 主人格はオリジナルとし、ユウカは私的 Pack とする

- 状態: Accepted
- 日付: 2026-11-22
- 関連: 統合ロードマップ v1.2(`/mnt/project-files/roadmap/integrated-roadmap-and-tech-selection.md`) C12

## 背景
VT はユウカを本体としていた。外見はミルティナ(仮)で、既存作品のキャラは公開発表に使えない。10年の自己同一性を自分で所有したい。

## 選択肢
| 案 | 長所 | 短所 |
|---|---|---|
| オリジナル主人格 + ユウカは私的 Pack | 権利と同一性を自分で持てる。ユウカの資産も活かせる | 人格を一から設計する |
| ユウカを主人格 | 資産がそのまま使える | 公開できない。外見と一致しない |

## 決定
2026-11-22 に作者が決定。オリジナルの主人格を人格仕様書 v1 で作り、ユウカは切り替え可能な私的 Pack にする。

## 結果
人格仕様書 v1 は 2027 Q1。セッションごとのキャラ紐づけ(実装方針 §7.2-5)が必要になる。ユウカ Pack はリポジトリに入れない。
