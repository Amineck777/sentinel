# 0107. 感情は PAD の内部状態とラベルの表出に分ける

- 状態: Proposed
- 日付: 2026-11-22
- 関連: 統合ロードマップ v1.2(`/mnt/project-files/roadmap/integrated-roadmap-and-tech-selection.md`) C6、VT ADR-0004

## 背景
VT は7値の Enum、10年戦略は PAD と評価理論。Enum は表情・声への写像に便利、PAD は時間変化と一貫性に必要。

## 選択肢
| 案 | 長所 | 短所 |
|---|---|---|
| PAD(内部)+ ラベル(表出) | 両方の長所 | 実装が2層になる |
| Enum のみ | 単純 | 気分の持続や減衰を表せない |
| PAD のみ | 連続的 | 表情・声への写像が難しい |

## 決定
LLM は `{emotion_label, appraisal}` を出し、辺縁系(感情エンジン)が PAD を3つの時定数(情動=秒、気分=時間〜日、性格=固定)で更新する。表出層が PAD とラベルから表情・声質を決める。

## 結果
2027 Q2 の感情エンジン v0 で実装。感情は機能的モデルであると人格仕様書に明記する。
