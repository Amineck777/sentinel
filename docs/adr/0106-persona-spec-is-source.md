# 0106. 人格の正は人格仕様書と学習データ、LoRA は派生物とする

- 状態: Proposed
- 日付: 2026-11-22
- 関連: 統合ロードマップ v1.2(`/mnt/project-files/roadmap/integrated-roadmap-and-tech-selection.md`) C5、VT ADR-0002

## 背景
VT は LoRA で人格を固定していた。しかしベースモデルは毎年入れ替える計画で、LoRA はベースモデルに縛られる。

## 選択肢
| 案 | 長所 | 短所 |
|---|---|---|
| 人格仕様書 + 学習データが正 | モデルを替えても人格を再現できる | 再学習と評価の手間 |
| LoRA が正 | 今すぐ動く | ベース変更のたびに人格を失う |

## 決定
人格仕様書と学習データ(`dataset*.jsonl`)を正とし、LoRA はベースモデルごとに再生成するキャッシュとする。ベースを替えたら再学習し、人格評価と FC 評価のゲートを通す。

## 結果
Character Pack の `llm.lora_path` はキャッシュの指し先という位置づけになる。Pack ごとのモデル指定(調査報告 D5)が必要。
