# 0108. 音声は既製話者を既定とし、学習型TTSは権利の明確な音源に限る

- 状態: Proposed
- 日付: 2026-11-22
- 関連: 統合ロードマップ v1.2(`/mnt/project-files/roadmap/integrated-roadmap-and-tech-selection.md`) C7、仕様書 §18・§19

## 背景
VT は VOICEVOX、仕様書の Track X2 はキャラ声の学習、10年戦略は実在人物の声の模倣を避ける方針。

## 選択肢
| 案 | 長所 | 短所 |
|---|---|---|
| VOICEVOX の既製話者 | すぐ使える。規約が明確 | 声の独自性は弱い |
| 学習型 TTS でキャラ声 | 独自の声 | 音源の権利問題 |

## 決定
既定は VOICEVOX の既製話者(各話者の規約に従う)。学習型 TTS は、自分の声や利用許諾のあるコーパスなど権利の明確な音源に限る。声優の声の再現はしない。

## 結果
口パクは VOICEVOX の音声クエリのモーラ情報から作る。
